# Small Totem Resource Pack v26.2

A lightweight Minecraft resource pack that makes totems of undying smaller and more compact.

## Version
- **Pack Format**: 26 (Minecraft 1.20.5+)
- **Version**: 26.2

## Contents
- Scaled down totem of undying model
- Optimized textures for smaller display

## Installation
1. Download or clone this repository
2. Place the folder in your Minecraft resource packs directory
3. Select it in Minecraft settings
4. Enjoy smaller totems!
